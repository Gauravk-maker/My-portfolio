# Gaurav Kumar 

Premium React portfolio website with:

- React + Vite
- Framer Motion animations
- Lucide icons
- Responsive dark glassmorphism UI
- Animated hero section
- Education timeline
- Skills showcase
- Project cards + project modal
- Achievements
- Contact form UI
- Resume download
- Mobile navigation
- Reduced-motion accessibility support

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite, usually:

```text
http://localhost:5173
```

## Build

```bash
npm run build
npm run preview
```

## Personalize

Update these placeholders in `src/App.jsx`:

- Email
- LinkedIn URL
- GitHub links
- Project GitHub/live URLs
- Resume file

Replace `public/resume.pdf` with your real resume PDF.

## Notes

The contact form is frontend-only. Connect it to Formspree, EmailJS, a serverless function, or your own backend to send actual emails.
